3. Modules détaillés

🎙️ STT — modules/stt.py

Rôle : Transcription parole → texte arabe/darija

Technologie : faster-whisper (modèle medium)

Langue : Arabe (couvre darija tunisien + français mélangé)

Audio : sounddevice, 16 000 Hz, VAD optionnel

Prompt initial : "مرحبا تليكوم تونس، عندي مشكلة في الخدمة"


faster-whisper sounddevice CPU / GPU

🧠 NLU — modules/nlu.py

Rôle : Détection d'intention + entités + sentiment

Stratégie hybride (priorité) :

① MLPredictor (TF-IDF ou AraBERT) → intent, service, wilaya, action

② Fallback règles regex → 14 intents couverts

Entités extraites : wilaya, délégation, téléphone, transaction ID

Correction localisation : override ML si délégation explicite dans le texte


regex multilingue darija + français 14 intents

🤖 MLPredictor — modules/ml_predictor.py

Rôle : Prédictions ML sur le texte

Backend 1 (prioritaire) : AraBERT fine-tuné (HuggingFace Transformers)

Backend 2 (fallback) : 8 modèles TF-IDF + LogisticRegression (ML.ipynb)

Prédit : issue_type, sentiment, service, wilaya, délégation, action, réponse ML

Moteur de décision : seuil sentiment + issue critique → escalade ou auto


AraBERT TF-IDF fallback LogisticRegression

🔍 RAG — modules/response_engine.py

Rôle : Récupération de réponse par similarité sémantique

Embedding : paraphrase-multilingual-MiniLM-L12-v2 (384 dim)

Index : FAISS IndexFlatIP (cosine sur vecteurs normalisés)

Encodage enrichi (v2) : chaque vecteur inclut issue_type + user_problem + user_answer → meilleure séparation par catégorie de problème

Requête enrichie (v2) : l'intent NLU est préfixé dans la requête d'embedding (étapes 1 et 2) → FAISS trouve le bon voisin même avec dialectal tunisien

2 index : problem_index (étape 1) + index principal (étape 2)

Filtrage : PASS1 (intent) → PASS2 (global) + bonus localisation +0.18

Personnalisation : substitution automatique de la localisation dans la réponse


FAISS sentence-transformers 6 687 conversations

🔊 TTS — via app.py (/api/tts) — v2

Rôle : Synthèse vocale arabe de la réponse bot

🆕 Priorité 1 : edge-tts — Microsoft Neural TTS, gratuit, sans clé API. Voix neurale tunisienne ar-TN-ReemNeural (femme) ou ar-TN-HediNeural (homme). Qualité Azure Cognitive Services. Rendu très naturel et humain.

Priorité 2 : ElevenLabs API (si clé configurée) — voix Josh, eleven_multilingual_v2

Priorité 3 : gTTS (Google TTS, gratuit, lang=ar) → fallback final

Navigateur : Web Speech API en dernier recours (client-side)


edge-tts ar-TN-ReemNeural 🆕 ElevenLabs gTTS fallback

🗣️ DialogManager — modules/dialog_manager.py

Rôle : Orchestration du flux de dialogue vocal

Mode vocal : boucle STT → NLU → RAG → TTS

Gère : états du dialogue, tour max (20), transfert humain

États : waiting_greeting → initial → clarifying → responding


State machine 20 tours max

🤝 HumanTransfer — modules/human_transfer.py

Rôle : Escalade vers agent humain si confiance trop basse

Déclenché si : RAG conf < seuil ET intent inconnu ET ≥ 2 tentatives

Ticket : résumé conversation + intent + priorité → human_queue.jsonl

API : /api/human_response pour résoudre + apprendre


Escalade Ticket JSONL

📚 Learning — modules/learning.py

Rôle : Apprentissage continu depuis les réponses humaines

Stockage : learned_interactions.jsonl (même format que dataset)

Auto-retrain : après 50 nouvelles interactions → rebuild FAISS

Intégration : index rechargé dynamiquement via reload_index()


Apprentissage continu Seuil: 50 interact.

9. Lancement du voicebot

▶ Option 1 — Double-clic sur LANCER_VOICEBOT.bat (Windows)
Le script installe automatiquement les dépendances si nécessaire,
lance Flask, et ouvre http://localhost:5000 dans le navigateur.
▶ Option 2 — Ligne de commande manuelle
cd pfe/PFE/
pip install -r requirements.txt
python app.py

# Puis ouvrir : http://localhost:5000
▶ Option 3 — Mode vocal (micro)
python voicebot_main.py # Mode vocal complet
python voicebot_main.py --text # Mode texte (debug)
python voicebot_main.py --build-index # Reconstruire FAISS
python voicebot_main.py --stats # Statistiques
